# New library recipes

Oct 9, 2026

56 new recipes, plus additions to 17 existing ones, for the 5,000 to 6,000 albums you're seeding through Tidarr now. They're adapted from the Occasion Library Playlist Playbook (built from the 8,539-album wantlist) and rewritten to the same AudioMuse rules as the Playlist recipes tab.

## Before you run these

These are for albums that aren't in your library yet. Run them once the downloads land and AudioMuse has analyzed them.

- **Wait for analysis.** AudioMuse can only pick songs it has analyzed. New albums get picked up by the nightly analysis, and a few thousand albums take several nights. The Analysis page shows when it's caught up.
- **Check the albums.** The "Check these are in" column lists two or three albums per recipe from the wantlist research. If those aren't in Navidrome yet, the recipe will come up thin or drift toward what you already have.
- **Missing artists are skipped.** A few prompts name well-known artists in the same lane that may not be on the wantlist, like Journey, Iron Maiden or Hans Zimmer. If you don't have them, AudioMuse skips them and uses the rest.
- **How these were changed from the AI draft.** The draft's prompts were short mood phrases with hours for sizes. Here every prompt names 4 to 9 artists, uses a song count and a per-artist limit, and keeps BPM as a range AudioMuse reads ("115 to 125 BPM"). The draft's "Pull from" column was for the Occasion Library app's filters, which AudioMuse can't use, so it's gone. The draft's suggested 2 to 3 songs per artist became 3 to 6, per your preference for more.
- **Every prompt is checked.** Each one was run through AudioMuse's own prompt reader, and its song count and per-artist limit come through as written.
